APIs, machine/model-specific experiments and old qualification claims. Use the
[current documentation index](../README.md) for supported instructions.

The root `PRISM_*`, `KVCACHED_COMPATIBILITY.md`, `DATABASE_MIGRATION.md`,
`model_registration_notes.md` and `models_request.md` documents are retained as historical
references. `docs/old_docs`, `docs/demo_prism.txt`, and `docs/vllm-upgrade-plan.md` are also
historical. Local research checkouts and downloaded papers are intentionally not packaged
as release evidence. The root Prism demo/acceptance scripts remain historical reproductions;
use the mode-independent qualification tool for current release traffic.
